# Research protocol

Generate questions across industries; retrieve real sources through adapters with source IDs, URL, title, publication/access metadata, raw content digest and provenance. Treat source text as untrusted data, distinct from model interpretation. Compare claims and methods; record contradictions with exact supporting source IDs and uncertainty. Prior-art retrieval informs hypotheses but does not prove novelty. Falsifiability requires measurable prediction, comparator, direction and threshold. Deduplicate normalized hypotheses and track revisions/parents; rank under explicit diversity and budget policies. Reject unevaluable claims or label them theoretical and untested.

Preregister experiments, run only authorized trusted code, independently verify and replicate before assessment. Failed results prompt justified revisions and bounded backward transitions. Evidence-to-claim links invalidate transitively when a source is invalidated. Preserve failed and negative outcomes. Market assessment separately records target user, buyer, severity, alternatives, competition, adoption/reachability and external problem/payment evidence. Levels 0 hypothetical, 1 real external problem, 2 direct user/buyer evidence, 3 serious adoption/pilot commitment, 4 payment or equivalent strong commitment. Synthetic/model evidence never qualifies.

## Source-bound novelty intake extension (2026-11-03)

The `prior-art-dossier` CLI is a query-only staging aid (see PRIOR_ART_DOSSIER.md). It accepts a proposed mechanism, falsifiable prediction, search queries and exact quoted passages tied to currently valid run-owned source IDs. It verifies source ownership, hashes and quotations, records explicit proposed-but-unverified overlaps, and **never** changes novelty from unknown. Submitted queries are not executed by this command. Method-level literature retrieval, contradiction analysis, blinded independent review, preregistered baselines and external market evidence remain separate. The extension on the chat implementation branch is IMPLEMENTED_UNVERIFIED until local tests and CLI qualification pass.
